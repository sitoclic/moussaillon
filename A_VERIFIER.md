# Points à vérifier

Ce fichier liste honnêtement les chiffres et affirmations du site qui n'ont pas pu être confirmés par une source fiable, ou qui méritent une relecture humaine. Chaque point correspond à un marqueur `// À VÉRIFIER` dans le code ou à `statut: "a-verifier"` dans `content/chiffres.ts`.

Dernière mise à jour : 6 novembre 2026.

## Chiffres

| Où                               | Affirmation                                   | Pourquoi la vérifier                                                                                                     |
| -------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `content/fr/glossary.ts` (mât)   | Le mât d'un IMOCA mesure « environ 29 m »     | La jauge IMOCA fixe une hauteur maximale ; la valeur exacte dépend du point de mesure (depuis le pont ou la flottaison). |
| `content/fr/glossary.ts` (bulbe) | Le bulbe d'un IMOCA pèse « environ 3 tonnes » | Ordre de grandeur couramment cité, sans source officielle précise.                                                       |

## Relecture conseillée

- Les coordonnées affichées sur la carte des escales sont décoratives et arrondies.
- La page « À propos » liste les sources générales ; les sources détaillées sont dans `content/chiffres.ts`.
